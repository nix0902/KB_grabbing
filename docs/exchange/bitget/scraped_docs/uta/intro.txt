统一账户(Unified Account)是Bitget面向广大用户推出的新一代交易系统,支持在一个账户中使用多币种资产同时交易现货和各类衍生品。这将会为用户的交易提供极大的便利,不再需要在多个账户之间进行资金划转,且不同业务线的盈亏可以互相抵消,有效地提升了用户的资金利用率。

账户模式​

统一账户为用户提供了三种新的账户模式:现货模式(Spot Mode)(未上线)、基础模式(Basic Mode)和进阶模式(Advanced Mode)),以满足不同用户的交易偏好与需求

账户模式	可交易产品	保证金支持	资格要求
现货模式（即将推出）	仅支持现货交易，不支持杠杆交易和合约交易	不使用保证金	受监管实体下的用户：默认适用该账户模式。
基础模式	现货、U本位永续合约及 USDC 永续合约	基础模式下，以 USDT 和 USDC 计价的币对共用同一保证金，这些产品之间的盈亏可以相互抵扣。	全球实体下注册的用户：默认适用该账户模式。需完成问卷以激活该模式。
进阶模式	现货、杠杆、U本位永续合约、USDC 永续合约、币本位	所有资产支持共同保证金	账户权益 ≥ 1000 美元，可完成问卷以激活此模式。

进阶模式下，所有产品类型的资产均可作为共享保证金使用，且盈亏可相互抵消，具体请参考此文档。

资产相关名词​
名词	解释
权益	跨保证金账户中特定币种的总权益。币种权益 = 余额 + 冻结保证金 + 未实现盈亏
余额	账户中特定币种的余额。
可用	账户中特定币种用于开仓的当前可用余额。可用 = 余额 + 未实现盈亏 注意：可用余额中的已实现盈亏可以用于开设合约仓位，但不能用于下达现货订单。
未实现盈亏	账户中以特定币种结算的所有合约仓位的总盈亏。 未实现盈亏 = USDT合约在全仓模式下的盈亏 + USDC合约在全仓模式下的盈亏 + 币本位合约在全仓模式下的盈亏
负债	负债 = ABS(min(余额 + 未实现盈亏, 0))
账户权益	账户中所有币种资产转换为法币后的净值。账户权益 = sum (币种权益 × 币种的美元价格)
维持保证金	账户中所有全仓仓位的总维持保证金。 维持保证金 = Sum[全仓仓位中币种的数量 × 币种价格] 维持保证金 = 仓位价值 × 维持保证金率
保证金率	用于衡量全仓账户风险的指标。 全仓账户的保证金率 = (维持保证金 + 部分强平交易手续费)÷账户权益。 维持保证金和部分强平交易手续费都通过将仓位大小和挂单大小相加来计算。
