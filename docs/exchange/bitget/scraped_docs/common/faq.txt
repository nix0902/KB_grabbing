FAQ

Q1： 如何获取API相关问题的技术支持？

A : 可以加入官方API技术支持群来反馈API问题，管理员会答复您。https://t.me/bitgetOpenapi

Q2: 下单交易对我是传 BTCUSDT_UMCBL 还是传 BTCUSDT ?

A : V2接口中使用BTCUSDT, V1接口中使用BTCUSDT_UMCBL

Q3 : websocket 订阅时 instId 传的是什么？

A : instId 传的是 合约信息接口 symbol；有的频道也可以使用default订阅全部symbol

Q4： 模拟盘充值模拟币？

A : 进入官方网站模拟盘交易页面

右侧在资产 下方点击充值按钮
提示:每次资产领取后需间隔72小时才能再次领取。

Q5： 交易员最小开单数量跟普通用户有什么区别 ？

A :
合约交易员最小开单额 请在该接口 交易员获取带单交易对返回参数minOpenCount获取
现货交易员最小开单额 请在该接口 交易员查询带单设置返回参数 minOpenCount 获取

Q6： 合约最大持有订单数 最大持有仓位数如何获取 ？

A : 请在 合约信息接口返回参数 maxSymbolOrderNum maxProductOrderNum maxPositionNum 获取

Q7： 如何判断您的身份是否是交易员 ？

A : 请在 获取账户信息返回参数 traderType 获取

Q8: 我使用的第三方服务器/外包服务器，并且不工作了，可以给我提供帮助吗？

A: :很抱歉，我们不支持对第三方服务器或者工具的帮助，请您联系三方服务供应商/或者开发商，寻求进一步的帮助。除此之外，将您在Bitget平台的API Key提供给任何第三方平台是存在安全风险的，您需要自行决定是否使用这些服务。请注意，我们不提供与编程相关的帮助。

Q9: 如果我忘记了API key的passphrase怎么办？

A: API key的passphrase不支持更改。需要您重新创建API key

Q10: API接口的限频规则是什么？

A: 1. 各api端口频率限制规则在文档有标注；2. 各API接口的限频互相独立计算；3. 总体有6000次/IP/分钟的限频规则,限频触发后，需要5分钟恢复

Q11: 如何得知接口每秒剩余的限频次数？

A: 请参考响应头中的x-mbx-used-remain-limit参数

Q12：是否有币种在现货和合约交易对中的名称不同？

A：是的。目前有三个币种有此情况。分别是 1.合约LUNA2 — 现货LUNA 2.合约ALT — 现货$ALT 3.合约MEME — 现货MEMECOIN

Q13: clientOid支持哪些格式？

A: clientOid支持[0-9], [a-z],[A-Z]以及[-,+,_,#],长度小于50

Q14: Bitget后端是否有固定的常规发布日？

A: 是的。当前后端固定的常规发布日为每周二、周三和周四的14:00 - 17:00 pm (UTC +8)(紧急发布除外)。 在常规发布时间段内，RestAPI可能会收到45001，40725，40808，40015报错响应, 用户在收到报错响应后重试即可，Websocket可能会在发布、更新期间断连，请websocket用户在代码中添加重连机制。

Q15: WebSocket 私有频道订阅是否有可能丢失消息？

A: 是的，存在消息丢失的可能性，建议用户始终使用 REST API 作为兜底措施。
