此文档供经纪商接入使用，如果您有一定的研发运营能力，想要搭建独有的交易平台和自主管理您的用户，独立经纪商服务是最好的选择。您则负责前端开发和用户运营，而Bitget为您提供后端技术和市场的流动性，赋能您的交易增值服务.

经纪商登陆后，在 API Keys管理 创建 API Key, 一定要设置IP 白名单
